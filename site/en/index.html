Everything you copied,

Clipboard history for macOS and Windows: it sits in the menubar, opens with one key, pastes on ⏎.

History stays in local SQLite. Two machines sync through your own NAS over WebDAV with end-to-end encryption.
One pure-Go binary: no cloud account, nothing uploaded anywhere else.

What it solves

Open and paste
The global shortcut is ⌘⇧V (Ctrl+Shift+V on Windows). The panel pops up next to the cursor and takes the keyboard: ⏎ pastes back into the app you came from, ⌘1-9 pastes one of the first nine, ⌥⏎ pastes plain text only, and a double click works too. The shortcut is remappable: click once in settings and press the combination, no accelerator syntax to memorise.
Capture
Text, rich text (HTML, RTF), images and files. Deduplicated by blake3 content hash with a use counter; the paste clipnest itself writes back is suppressed by a guard, so nothing duplicates itself.
Search
SQLite FTS5 full text; two-character queries fall back to LIKE, because a trigram index cannot match anything shorter than three characters. Kind and group filters, an instant preview on the right, and paging that continues as you scroll.
Tidy up
Pin, star, note, group, mark sensitive. ⌘-click several rows to delete in bulk, with a 10-second undo. None of these touch the sort timestamp (they write meta_at instead), so a sync never reshuffles the whole list because of them.
Sensitive apps
Filtered by foreground app identity (bundle id on macOS, process name on Windows) rather than by guessing content: whatever you copy inside a password manager does not get stored by default.
Sync
WebDAV on your own NAS plus end-to-end encryption (argon2id + chacha20poly1305), so the server only ever holds ciphertext. Pushes 1.2 s after a capture, switches between LAN and Tailscale addresses automatically, and keeps every increment as its own file for 7 days, so a peer that was offline catches up in one round instead of losing the middle ones.
Backup
CNST1 encrypted containers, imported and exported with the same passphrase; clearing all history writes one first.
Small
Pure Go with CGO_ENABLED=0, the UI drawn by mygo: no WebView, no Node, no Electron. Data lives in ~/Library/Application Support/clipnest (%APPDATA%\clipnest on Windows).

Connecting two machines the NAS only holds ciphertext

Fill this in once on each machine under Settings → Sync. The two passphrases are not the same thing, and each is stored in the system credential store:

FieldStored asRequirement
WebDAV passwordSystem credential store
clipnest-webdav/device-name		The NAS account password; it may differ per device
Encryption passphraseSystem credential store
clipnest-sync/device-name		Shared by end-to-end encryption and backups; both machines must use the same string, or what you pull down cannot be decrypted
/data/clipnest/ ├── mac-a-20261119T012345.678.json ← one file per increment, timestamped, never overwritten ├── mac-b-20261119T013012.101.json ← same on Windows, each machine writes its own ├── mac-a.json / mac-b.json ← the old 1.3.2 and earlier format (still readable) └── blobs/ab/abcdef…png ← image originals, named by content hash, shared

The device names must differ, they are what separates the files. A fresh device has no export watermark yet, so its first sync pushes the whole history and it gets everything the other machine had. If a peer is missing one increment later on, “Re-push the whole history…” in settings clears the watermark and pushes everything again (idempotent: images go through a ledger and are not re-uploaded). Errors are shown verbatim in the panel footer and in settings: PROPFIND: 401 means a wrong WebDAV password, x509: certificate signed by unknown authority means a self-signed certificate you did not allow.

Script options (environment variables when piping): --from github|gitee|auto (default auto, Gitee first) · --version vX.Y.Z · --dir DIR · --no-open. The same scripts ship with every release.

Unsigned and not notarized (there is no Apple Developer Program subscription): package managers and curl / irm downloads carry no quarantine flag, so Gatekeeper and SmartScreen stay quiet. Only a zip downloaded in a browser needs “right click → Open” or xattr -dr com.apple.quarantine. The in-app update check only reports, it never installs, and the source can be Gitee, GitHub, either automatically, or a custom URL.

Questions

⏎ only copies, nothing gets pasted
Pasting is done by synthesising ⌘V through the accessibility API. Without the grant the panel shows a hint bar with a “Grant access” button that opens the right system pane. On macOS there is one more case: after switching from an ad-hoc signature to a fixed self-signed identity, the old grant no longer matches, so run tccutil reset Accessibility com.clipnest.app and tick it again.
Does it work on Windows?
The code is on par with macOS and cross-compiles, but real-hardware smoke testing is not done yet: panel focus stealing, the foreground lock, high DPI, tray, single instance and autostart still need a machine to verify them. This page states that rather than claiming support it cannot back up.
Where is my data, and how do I remove all of it?
~/Library/Application Support/clipnest on macOS, %APPDATA%\clipnest on Windows: a clipnest.db (SQLite), image shards and rotating logs. Delete that directory and the two credential entries and nothing is left elsewhere. Clearing history can also be done inside the app, which asks you to type a confirmation word and writes an encrypted backup first.
Does syncing send my clipboard somewhere?
No. There is no cloud account and no telemetry. The target is the WebDAV directory you configure, and content is encrypted before it leaves the machine, so the server only sees ciphertext. Passphrases live in the system keychain or credential manager.
Why not Electron or Tauri?
Clipboard monitoring, global shortcuts, files on the clipboard and moving a window across displays all exist in the framework layer. Pure-Go drawing lets both platforms share one codebase, cross-compiles without an extra toolchain, and the binary needs no webview runtime.
Can I read the code?
Yes. MIT, go test ./... with 193 tests, and a pre-commit hook that runs vet, the tests and a Windows cross-compile. The architecture and its 12 behavioural contracts are in docs/路线图.md.

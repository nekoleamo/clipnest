# clipnest 1.0.0

跨平台（macOS / Windows）剪贴板历史管理器：菜单栏常驻、`⌘⇧V`（Windows 是 `Ctrl+Shift+V`）唤出面板、
搜索、回车粘贴；支持文本/文件/图片条目、敏感应用过滤、可选的 WebDAV（NAS）端到端加密同步。

## 安装

### macOS（Homebrew，推荐）

```bash
brew tap <owner>/clipnest
brew install --cask clipnest
```

cask 会删掉下载标记，装完直接可用。

### macOS（zip）

1. 下载 `clipnest-1.0.0-macos.zip` 解压，把 `clipnest.app` 拖进「应用程序」
2. **首次打开**：右键 → 打开；macOS 15+ 需要到「系统设置 → 隐私与安全性」点「仍要打开」
3. 或终端一条命令：`xattr -dr com.apple.quarantine /Applications/clipnest.app`

> 本项目**没有 Apple Developer 会员**，因此不签名、不公证。上面的放行步骤是正常现象；
> 请自行判断是否信任（源码全在仓库里，也可以自己 `cargo build`）。

### Windows

下载 `clipnest-1.0.0-windows-x86_64.zip` 解压，双击 `clipnest.exe`。
SmartScreen 会提示「未知发布者」→「更多信息」→「仍要运行」（只需一次）。

### 关于更新

首次安装放行一次之后，**后续版本会在应用内自动更新**（偏好设置 → 更新 → 检查更新）。
应用自己下载的文件不带 macOS/Windows 的"下载标记"，所以更新不会再被 Gatekeeper / SmartScreen 拦。
更新包用项目自己的 ed25519 公钥验签（`latest.json.sig`），不是「什么都不验」。

## 首次使用

- 托盘/菜单栏出现 `❐`，点它或按 `⌘⇧V` 唤出面板
- 若要自动粘贴，需在「系统设置 → 隐私与安全性 → 辅助功能」里勾选 clipnest
- 同步在「偏好设置… → 同步」里配：WebDAV 地址、用户名、密码（存系统钥匙串）、同步口令（端到端加密）

## 已知限制

- 未签名未公证（见上）：首次安装需要放行一次；之后应用内自更新不会再被拦
- 真拖拽导出未实现（nsh 无 drag-out API），用 `⌘O` 导出文件 + `⌘V` 粘文件代替
- 同步的冲突策略是「`updated_at` 新的赢」，界面上只显示汇总数量

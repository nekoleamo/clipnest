# 路线图

> 产品定位与技术决策的**总纲**。日常进度看 `执行计划-下一步.md`，发版看 `发布.md`。

## 一、定位（已定，不再讨论）

跨平台（macOS + Windows）剪贴板历史管理器：托盘常驻、全局快捷键唤出、回车粘贴，历史可通过
**自有 NAS** 同步，不依赖第三方云。不做 WebView / Electron / Node，不做云端账号体系，不做移动端。

## 二、技术决策

| 项 | 决策 | 依据 |
| --- | --- | --- |
| GUI | **Go + mygo v0.9.1**（`mygo/ui` 纯 Go 自绘） | 挪窗、多屏、剪贴板监听、文件进剪贴板、⌘⇧ 组合键都是现成 API |
| 语言 | **纯 Go，无 cgo** | 交叉编译 Windows 不需要额外工具链；平台缺口用 `purego` 补 |
| 壳 | `WindowOptions{Panel: true}` = `NSPanel`，非激活样式 | 抢键盘但不激活 app，不用 nsh 那套隐藏主窗补丁 |
| 剪贴板 | `mygo.Clipboard`（`OnChanged` + `Formats`/`Read`） | 内置 TIFF/DIB 转 PNG 与文件列表读写 |
| 存储 | SQLite + FTS5（`modernc.org/sqlite`） | 纯 Go；trigram 分词，短词降级 LIKE |
| 同步 | WebDAV（NAS 自带）+ 端到端加密 | 零部署；口令存系统凭据（钥匙串 / 凭据管理器 / libsecret） |
| 版本 | 锁 `mygo v0.9.1` | 0.x 阶段，升级单独一轮并复测（坑位见 `AGENTS.md`） |

框架调用集中在 `ui/` 与少数平台适配点，便于将来升级。

## 四、12 条行为契约（改一条要重开评估）

1. `content_hash = blake3("<kind>:<content>")`
2. HTML / RTF 条目必须同时具备 plain 文本才入库
3. 文件条目 `content` 为换行分隔路径，`file_types` 为 `d`/`f` 串
4. 图片 `content` 为 PNG 文件名，资源按 hash 前 2 位分片存 `origin/`、`thumbnails/`
5. 去重命中只 `use_count + 1` 并刷新 `updated_at`
6. 收藏 / 置顶 / 敏感 / 备注 / 分组的变更**不**刷新 `updated_at`（同步另看 `meta_at`）
7. 搜索：长词走 FTS5，短词降级 LIKE
8. 置顶恒排最前
9. 收藏与置顶受清理保护
10. 自身写回必须被 guard 抑制，不产生新记录
11. `CNST1` 加密容器字节布局不变（兼容旧备份）
12. 旧版数据导入只承诺历史记录，不扩大到设置迁移

## 五、风险

| 风险 | 缓解 |
| --- | --- |
| Windows 真机行为未验（抢焦点、SetForegroundWindow、DIB、高 DPI） | 能力对照表逐项待验；`tools/win-smoke.ps1` 是低层探针 |
| 同步协议正确性 | 以 hash 为唯一键 upsert；先传后合并；删除用墓碑；`meta_at` 带元数据 |
| 面板焦点/时序回归 | 交易类改动后跑 `go test ./...`（含面板帧级测试） |
| 未签名分发的 Gatekeeper / SmartScreen 摩擦 | 走包管理器与一键脚本（下载不带隔离标记）；文档写明浏览器直下的处理 |
| 辅助功能权限被撤销 | 面板顶部提示条 + 「去授权」直达系统设置 |

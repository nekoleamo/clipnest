# 变更记录

## 1.1.0（2026-11-18）

依赖升级 + 一处数据安全修复，功能与 1.0.1 一致。

- **升级**：`mygo` 0.9.1 → **0.10.0**（API 与行为无破坏，`go test ./...`、交叉编译、headless 渲染均复验），
  以及 `klauspost/cpuid`、`golang.org/x/net`、`modernc.org/libc`、`modernc.org/memory`
- **修（数据安全）**：连删两批条目时，第一批的 10 秒清理定时器会把**第二批还在撤销窗口内的图片文件**
  删掉，导致「撤销」恢复出一个原图缺失的条目；现在每批只清理自己那批的文件，上一批被替换时立即回收
- 清理：`staticcheck` 全绿（删掉 `rowMenuBuilds`、`fitSize`、`cgHandle`、测试里没用的 helper）
- 修：WebDAV 口令写入系统凭据失败时不再静默，会在设置窗报出来
- 文档：mygo 版本号同步到各处；`docs/变更记录.md` 补 1.0.1 / 1.1.0

## 1.0.1（2026-11-18）

安装与文档修复，**应用功能与 1.0.0 相同**（二进制因内嵌版本号不同而不同）。

- 修：`install.sh` 的 `CLIPNEST_FROM` / `CLIPNEST_VERSION` / `CLIPNEST_DIR` 环境变量不生效
  （管道执行 `curl … | sh` 时只能靠环境变量选源，之前会被忽略，默默走 GitHub）
- 修：`tools/gitee-release.sh` 建 release 用 formData（Gitee 不吃 JSON body，`target_commitish` 必填），
  并补 token 身份 / 仓库可读性预检、失败时打印接口原文
- 新增：`tools/gitee-release_test.sh`（假 Gitee API，7 条断言）、`tools/install_test.sh` 增到 8 条
- 文档：README 与 `docs/` 精简重写；版权署名改为账号名
- 分发：Homebrew tap 与 Scoop bucket 都提供 GitHub 版与 Gitee 镜像版（cask/manifest 的下载地址分别指向对应站点）

## 1.0.0（2026-11-17）

首个 Go + mygo 版本发布。

- 采集：文本 / HTML / RTF / 图片 / 文件；内容哈希去重 + 使用次数；敏感应用过滤；自身写回抑制
- 面板：搜索（trigram + 短词 LIKE）、类型与分组筛选、右栏预览、分页加载、搜索命中高亮
- 键盘与鼠标：`⏎` 粘贴、`⌘1-9` 直贴、`⌘D` 删、`⌘P` 置顶、`⌘S` 收藏、`⌘E` 敏感、`⌘Y` 复制、`⌘O` 导出、
  `⌥⏎` 纯文本、`PgUp/PgDn` 翻页、`⌘F` 回搜索框；双击粘贴、`⌘` 点多选、右键菜单、拖拽导出
- 整理：置顶 / 收藏 / 备注 / 分组；多选批量删除；删除后 10 秒可撤销；长文本「查看全文」
- 同步：WebDAV 增量 + 端到端加密（argon2id + chacha20poly1305），局域网/Tailscale 双地址自动切换，
  采集后 1.2 秒实时推送；元数据改动经 `meta_at` 同步
- 其他：`CNST1` 加密备份、暂停记录、运行期日志轮转、检查更新（GitHub / Gitee / 自定义源，只查不装）、单实例、开机自启
- 分发：GitHub Release（zip / dmg / `SHA256SUMS`）、Gitee 镜像、Homebrew tap、Scoop bucket、
  `curl` / `irm` 一键安装（校验 SHA256，双源自动切换）

### 已确认的坑（中文输入法）

面板拿到键盘后，输入源是中文拼音时**第一次回车只提交候选、不触发 `Submitted()`**：合成期间 AppKit 把 `KeyPressed` 扣住（mygo `surface.keyDown` 的 `withheld`），只有 `KeyUp` 过来。
所以打字后是「⏎ 提交 → ⏎ 粘贴」；不输入直接 ⏎ 一次就粘。`⌘1-9` 带 Cmd 不受输入法影响。

## 二点五、实时同步与局域网/Tailscale 自动切换（2026-11-16 晚）

| 事项 | 实现 |
| --- | --- |
| 双地址 | `Backend.URL`（局域网）+ `Backend.FallbackURL`（Tailscale / 外网），设置窗可填 |
| 自动切换 | `internal/sync/endpoint.go`：每轮前用 1.2 秒 TCP 探测，局域网优先，不通走备用；选中结果缓存 5 分钟，同步失败就清缓存重探 |
| 实时推送 | `App.RequestRealtimeSync()`：采集后 1.2 秒防抖跑一轮，`syncBusy` 保证不重叠，期间的请求结束后补跑 |
| 实时拉取 | `Config.Realtime` + `PullSecs`（默认 5 秒，夹 2–300）；未开实时则仍按 `IntervalSecs` 定时 |
| 安静状态 | 「什么都没变」不刷底部状态；面板/设置窗显示「上次同步 x 分钟前 · 局域网 https://…」 |
| 排查工具 | `go run ./cmd/syncprobe [-probe|-list]`：打印选中的入口、远端包名与大小、一轮耗时 |

本机实测（2026-11-16）：
- 局域网通：`入口：局域网 https://192.168.110.94:5006`，探测 3ms，一轮 46ms（List 46ms / Get 6ms）
- 把主地址改成不可路由的 10.255.255.1 后：`入口：Tailscale https://nekoleamo-nas.tail0a74c7.ts.net:5006`，探测 1.218s（含等满 1.2s 超时）
- 本地目录双实例：A 推到远端 `A.json`，B 一个轮询周期内拉到条目（`pulled=1 +1`）

## 四、自检钩子（环境变量）

| 变量 | 作用 |
| --- | --- |
| `CLIPNEST_DATA_DIR` | 数据根覆盖（测试用临时目录） |

### T2 schema 与迁移（对齐行为契约）

草案（细节按契约 1–6 调整）：

```sql
CREATE TABLE IF NOT EXISTS items (
  id            INTEGER PRIMARY KEY,
  content_hash  TEXT NOT NULL UNIQUE,   -- blake3("<kind>:<content>")
  kind          TEXT NOT NULL,          -- text | html | rtf | image | files
  content       TEXT NOT NULL,          -- 文本原文 / 图片文件名 / 换行路径
  file_types    TEXT,                   -- 'd/f' 串，仅 files
  width         INTEGER, height INTEGER,-- 仅 image
  use_count     INTEGER NOT NULL DEFAULT 1,
  pinned        INTEGER NOT NULL DEFAULT 0,
  favorite      INTEGER NOT NULL DEFAULT 0,
  note          TEXT,
  group_id      INTEGER REFERENCES groups(id),
  sensitive     INTEGER NOT NULL DEFAULT 0,
  created_at    TEXT NOT NULL,
  updated_at    TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS groups (id INTEGER PRIMARY KEY, name TEXT NOT NULL UNIQUE, sort INTEGER);
CREATE VIRTUAL TABLE IF NOT EXISTS items_fts USING fts5(
  content, note, content='items', content_rowid='id', tokenize='trigram'
);
-- 触发器保持 items_fts 与 items 同步（insert/update/delete）
CREATE TABLE IF NOT EXISTS meta (key TEXT PRIMARY KEY, value TEXT);  -- schema_version 等
```

要点：
- 迁移用 `user_version`（`PRAGMA user_version`）递增，不用外部 migration 框架
- `tokenize='trigram'` 支持中文与子串搜索；契约 7 的「短词降级 LIKE」在查询层实现

**验收**：测试覆盖建库、重复打开、版本号推进、FTS 与触发器同步（增/改/删各一条）。

### T3 入库与去重（契约 1、3、4、5、6）

- `db::items::upsert(&conn, NewItem) -> UpsertResult { Inserted, Deduped }`
- 去重命中：`use_count += 1`、`updated_at = now`，其余字段不动
- 收藏/置顶/备注/分组变更走独立 `update_meta()`，**不**触碰 `updated_at`
- `content_hash` 计算集中在 `model::content_hash(kind, content)`

**验收**：同内容连续入库 3 次 → 1 行、`use_count = 3`；改备注后 `updated_at` 不变。

### T4 查询与搜索（契约 7、8）

- `db::search::query(conn, q, filter) -> Vec<Item>`：空查询返回按 `pinned DESC, updated_at DESC` 分页
- 长词（≥3 字符）走 FTS5，短词/特殊字符降级 `LIKE`（契约 7）
- 支持按 kind、分组、收藏过滤

**验收**：1000 条假数据下，中文/英文/子串/短词各一组断言；查询耗时 < 20 ms（`Instant` 断言记录到测试输出，不做硬门槛）。

### T5 加密备份（契约 11 的简化版）

- 格式 v1：`magic "CNST1" + salt(16) + nonce(12) + ciphertext(chacha20poly1305)`，key 由 argon2id 从口令派生
- `backup::export(path, passphrase, items, groups)` / `backup::import(path, passphrase)`
- 明确：**只承诺自身格式**，EcoPaste 的 `.ecopastebak` 兼容留到 P6 再评估

**验收**：导出→导入 round-trip 数据完全一致；错误口令报错不 panic；二次导入同数据不产生重复。

## 4. P4 同步设计要点（先想清楚，P1/P2 期间不要动手）

- 传输：WebDAV（`PUT/GET/PROPFIND`），目录 `/clipnest/` 下按设备写 `devices/<deviceId>.jsonl` + `manifest.json`
- 载荷：加密的条目增量（复用 T5 的加密原语），**不传 SQLite 库文件**（R7）
- 合并：以 `content_hash` 为键的 upsert；`use_count` 取 max 或求和（需定策略，建议 max + 本机累加）
- 删除：tombstone（`deleted_at`），保留 30 天
- 定时：变化后防抖 5–10 s + 每 30 分钟兜底

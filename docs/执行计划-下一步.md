```bash
source "$HOME/.cargo/env" 2>/dev/null   # 不再需要，留着无害
go test ./...                            # 78 项
go vet ./...

CLIPNEST_DATA_DIR=/tmp/x CLIPNEST_AUTOOPEN=1 CLIPNEST_AUTOQUIT=8 ./clipnest   # 自检
```

## 四、自检钩子（环境变量）

| 变量 | 作用 |
| --- | --- |
| `CLIPNEST_DATA_DIR` | 数据根覆盖（测试用临时目录） |
| `CLIPNEST_AUTOOPEN` | 启动 2 秒后自动弹面板 |
| `CLIPNEST_AUTOQUIT=<秒>` | 到点退出（自动化冒烟用） |
| `SPIKE_NO_AX` | 假装没有辅助功能授权，验提示条 |

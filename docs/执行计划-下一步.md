## 三、日常命令

```bash
go test ./...                      # 192 项
go vet ./...
GOOS=windows go build ./...
go tool mygo build                 # 打包 .app + dmg
go run ./cmd/uishot -out /tmp/p.png            # 面板版式（headless 出图）
go run ./cmd/uishot -prefs -w 620 -h 960 -out /tmp/q.png   # 设置窗版式
bash tools/install_test.sh         # 一键安装脚本端到端（假发行版服务器）
bash tools/gitee-release_test.sh   # Gitee 镜像脚本端到端（假 API）
bash tools/pre-push.sh             # 提交前校验（钩子已挂）
```

自检钩子（环境变量）：

| 变量 | 作用 |
| --- | --- |
| `CLIPNEST_DATA_DIR` | 数据根覆盖（临时目录，测试用） |
| `CLIPNEST_AUTOOPEN=1` | 启动 2 秒后自动弹面板 |
| `CLIPNEST_AUTOQUIT=<秒>` | 到点退出（自动化冒烟） |
| `CLIPNEST_AUTOLOGIN=1\|0` | 注册 / 取消登录项 |
| `SPIKE_NO_AX` | 假装没授辅助功能，验提示条 |

## 四、已知限制

- **RTF 在 Windows 上不会产生**：mygo 没映射 Windows 的 `Rich Text Format`；同步过来的 RTF 仍可粘（写回带 plain 兜底）
- Windows 前台锁可能被系统拒绝：`paste.ClaimForeground()` 失败只记日志
- 未签名：浏览器直下 zip 会被拦一次；包管理器与一键脚本不受影响
